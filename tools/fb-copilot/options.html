Contractez Copilot — Opțiuni

Conexiune la server

Extensia trimite postările citite spre serverul Contractez. Tokenul este valoarea variabilei OUTREACH_TOKEN din mediul serverului.

Permise: https://contractez.ro (producție) sau http://localhost:3000 (dezvoltare).
Tokenul rămâne doar în acest browser (nu se sincronizează în contul Google).

Cache local

Extensia ține minte ultimele ~20.000 de id-uri trimise, ca să nu le retrimită. Golește cache-ul doar dacă serverul a fost resetat sau vrei să retrimiți tot ce vezi.
